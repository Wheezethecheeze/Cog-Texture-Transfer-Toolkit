# Cog Texture Transfer Toolkit

these blender files are here to help content pack creators both with porting cog head textures between Toontown Rewritten and Toontown Corporate Clash, as well as making the process to MAKE rewritten heads a bit easier. those TTO uv maps are really hard to work with sometimes!! 





requires Blender 4.5.4 LTS or higher, photo editing software (ex. photoshop, gimp, krita) for manual editing (seams, stitching palettized cog textures together, flunky glasses for now because when i tried to transfer using blender it just crashed it. owie.), and basic content pack creation knowledge.



check out the user manual pdf to get started!
